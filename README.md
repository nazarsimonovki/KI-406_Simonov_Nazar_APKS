# Лабораторна робота № 1: Проєктування AI-агента для автоматизації розробки та CI/CD

## Інформація про студента
- **ПІБ:** Сімонов Назар Андрійович
- **Група:** КІ-406
- **Варіант:** 1 (C++, CMake, GoogleTest/CTest)

## Опис проєкту
Спеціалізований AI-агент (Build Engineer) для повної автоматизації життєвого циклу розробки кросплатформного застосунку "Hello World" мовою C++17 із системою складання CMake, тестуванням через GoogleTest/CTest та CI/CD конвеєром у GitHub Actions.

Характеристики проєкту:
- Мова програмування: C++17
- Система складання: CMake (мінімальна версія 3.20)
- Модульне тестування: GoogleTest v1.14.0 (підключення через FetchContent), CTest
- CI/CD конвеєр: GitHub Actions (матриця Ubuntu, Windows, macOS)

## Інтерактивні слеш-команди агента

Команди агента інтегровані у випадаюче меню GitHub Copilot Chat у середовищі VS Code завдяки конфігураційним файлам `.github/prompts/*.prompt.md`.

При введенні символу `/` у вікні Copilot Chat доступні такі команди:
- `/init` — головний оркестратор: послідовний запуск усього ланцюжка розгортання та тестування проєкту.
- `/git-init` — ініціалізація локального репозиторію Git та налаштування файлу `.gitignore`.
- `/create-project` — створення структури каталогів (`src/`, `tests/`, `docs/`) та вихідних файлів (`src/main.cpp`, `src/addition.hpp`).
- `/create-build` — генерація конфігураційного файлу `CMakeLists.txt` та модульного тесту `tests/test_main.cpp`.
- `/create-actions` — створення файлу workflow `.github/workflows/ci.yml` та скриптів автоматизації `ci.bat` і `ci.sh`.
- `/check` — статична та динамічна перевірка коректності структури файлів, компіляції та виконання тестів.

### Інструкція з виклику

1. Відкрити репозиторій у середовищі VS Code.
2. Відкрити панель GitHub Copilot Chat (`Ctrl+Alt+I` або `Ctrl+Shift+I`).
3. Ввести символ `/` та обрати потрібну команду з інтерактивного списку, або ввести безпосередньо:
   ```text
   /init
   ```

## Локальна збірка та запуск тестів

Вимоги до оточення: CMake 3.20+, компілятор C++17 (MSVC / GCC / Clang).

Швидкий запуск через скрипти автоматизації:
- Windows:
  ```cmd
  ci.bat
  ```
- Linux / macOS:
  ```bash
  chmod +x ci.sh
  ./ci.sh
  ```

Покрокове виконання:
```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Виконуваний файл застосунку: `build/Release/hello.exe` (Windows) або `build/hello` (Unix).
