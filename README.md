# Лабораторна робота № 1: Проєктування AI-агента для автоматизації розробки та CI/CD

## Інформація про студента
- **ПІБ:** Сімонов Назар Андрійович
- **Група:** КІ-406
- **Варіант:** 1 (C++, CMake, GoogleTest/CTest)

## Опис проєкту
Цей репозиторій містить спеціалізованого AI-агента, створеного для автоматизації процесів розробки, складання та тестування кросплатформного проєкту "Hello World". 

Основні характеристики згенерованого проєкту:
- **Мова програмування:** C++
- **Система складання:** CMake
- **Фреймворк тестування:** GoogleTest / CTest
- **CI/CD:** GitHub Actions

Проєкт демонструє використання Agentic AI: агент керується маніфестом, має чітко визначені навички для виконання ізольованих завдань і команди для керування процесом.

## Як запустити агента

Для взаємодії з агентом та генерації проєкту використовується GitHub Copilot Chat у середовищі VS Code.

1. Відкрийте цей репозиторій у VS Code.
2. Переконайтеся, що ви авторизовані у GitHub Copilot під своїм акаунтом.
3. Відкрийте панель Copilot Chat.
4. Скопіюйте та відправте агенту команду-оркестратор `init`, звернувшись до його маніфесту:
   
   ```text
   @workspace Прочитай файл .github/agents/build-engineer.agent.md та виконай команду init, послідовно запустивши всі кроки для мого варіанта (C++, CMake).
   ```

## Збірка та тестування HelloWorldApp

Потрібні CMake і сумісний компілятор C++17.

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Застосунок виводить `Hello, World!`; CTest запускає тест `BasicAddition`.
