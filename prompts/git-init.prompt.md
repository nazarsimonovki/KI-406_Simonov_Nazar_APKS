# Command: git-init

## Передумови
- Наявність встановленого клієнта Git.
- Робоча директорія для проєкту.

## Дії
- Перевірити стан репозиторію; якщо Git не ініціалізовано, виконати ініціалізацію.
- Створити або оновити файл `.gitignore`, щоб виключити директорії збірки (наприклад, `build/`), бінарні файли, кеші та секрети.
- Показати поточний стан Git.

## Очікувані файли
- `.gitignore` (з доданою папкою `build/`)

## Команди перевірки
- `git status`

## Повідомлення про помилку
- "Помилка git-init: Не вдалося ініціалізувати Git або оновити .gitignore. Перевірте права доступу."
